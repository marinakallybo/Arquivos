# CineLista

Catálogo de filmes com lista "Quero assistir" (HTML, CSS e JavaScript puro, com POO e CRUD).

## Paleta
| Uso | Claro | Escuro |
|---|---|---|
| Fundo | #F7F6FB | #12101C |
| Cartões | #FFFFFF | #1C1930 |
| Texto | #1B1930 | #F1EFFA |
| Texto secundário | #5F5C78 | #A7A3C4 |
| Destaque | #5B34D6 | #9A7DFF |
| Sucesso / Erro | #166A3A / #B42318 | idem |

## Fontes
Fraunces (títulos) e Inter (corpo), via Google Fonts.

## Imagens
Lorem Picsum (https://picsum.photos), imagens de teste.

## Funcionalidades
CRUD de filmes, busca em tempo real, filtro por gênero, ordenação, lista "Quero assistir" com tempo total, tema claro/escuro e dados salvos no localStorage.
